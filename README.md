# 台股三大法人買賣超分析工具

供個人電腦執行的上市股票盤後資料網站。後端使用 Python + Flask，資料存於 SQLite；前端為原生 HTML/CSS/JavaScript，圖表以 SVG 繪製，不需另外安裝前端套件。

## 啟動方式（Windows PowerShell）

本專案已備妥 Python 3.12.10 專案內執行環境，並安裝 `requirements.txt` 所需套件。於專案資料夾以 PowerShell 執行：

```powershell
.\.python312\python.exe --version
.\.python312\python.exe app.py
```

瀏覽器開啟 <http://127.0.0.1:5000>。若要改用系統已安裝的 Python 3.10 以上版本，也可建立虛擬環境：

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

## 資料更新

首次啟動後按首頁「更新資料」。系統逐日查詢最近 40 個日曆日的 TWSE T86，取得涵蓋約 20 個交易日的排行與個股歷史資料；後續可手動再次更新。無雲端排程，也不會執行盤中法人買賣推估。更新失敗時畫面會顯示原因，舊資料仍可使用。

資料庫位於 `data/twse.sqlite3`，原始成功回應保存在 `data/raw/T86_YYYYMMDD.json`。資料以「交易日、股票、法人類別、市場別」作唯一鍵，重複更新會更新該筆資料。可用環境變數 `TWSE_DB_PATH` 指定資料庫位置。

## 欄位定義

- 外資：TWSE「外陸資買進/賣出股數（不含外資自營商）」。
- 投信：TWSE「投信買進/賣出股數」。
- 自營商：自行買賣與避險買進/賣出分別加總。
- 三大法人合計買賣超：使用 TWSE 官方合計淨額欄位；合計買進/賣出為前述三類買進/賣出相加。
- 買賣超股數 = 買進股數 − 賣出股數；張數換算為股數 ÷ 1,000。
- T86 回應標示單位為股，包含一般、零股、盤後定價及鉅額，不含拍賣及標購。

每筆資料儲存交易日期、股票代號/名稱、市場別、法人類別、買進/賣出/淨買賣超股數、來源及擷取時間。欄位不符或淨額驗算不合時，該次更新停止並保留錯誤訊息。

## 資料來源與授權

使用臺灣證券交易所「三大法人買賣超日報 T86」盤後 JSON：<https://www.twse.com.tw/rwd/zh/fund/T86>。查詢方式為 `response=json`、`date=YYYYMMDD`、`selectType=ALLBUT0999`。TWSE 資料商說明列出 T86 不含鉅額資料於交易日 18:00 產製；官網互動頁資料涵蓋一般、零股、盤後定價與鉅額，且單位為股。實際日期可視端點資料更新情形而不同。

本工具定位為個人本機研究工具。TWSE 網站使用條款限制未經同意以自動化程式下載資料，並指出經政府資料開放平台授權提供公眾使用之資料屬例外；但 T86 本端點、資料集授權及再散布範圍應由使用者於部署前自行向 TWSE 確認。對外提供服務、營運或再散布之前，應先確認資料授權及相關契約，不可將本機用途視為商用授權。

## 目前限制

- 僅上市市場；資料模型保留市場別欄位，以便日後擴充上櫃市場。
- 更新限手動觸發，逐日回溯 40 個日曆日；若假期或 TWSE 暫停發布導致交易日不足，個股頁會顯示實際取得天數。
- 首次更新會向 TWSE 發出多次逐日請求，需可連線至官方網站。服務無法連線、回應欄位變更或資料驗算失敗時，不會把該日資料寫成有效結果。
- 排行最多顯示 200 筆，搜尋限制在目前最新有資料交易日。
- 不含股價預測、投資建議、自動下單或盤中法人即時買賣判斷。
